# 系统体检检查清单

本清单以当前正式实现为准：`app.py -> classroom_app -> templates/app_shell.html -> static/app/main.js`。

## 1. 功能链路

- 登录、退出、会话状态
- 单图检测：上传、结果图、摘要、报告
- 批量检测：多图上传、结果列表、主预览切换、报告 ZIP
- 视频检测：启动、进度、停止、完成/失败状态、报告
- 实时摄像头：诊断、启动、持续读取、停止、历史记录
- 历史记录：筛选、排序、定位、多选、批量导出

## 2. UI 与显示

- 登录页桌面/窄屏显示
- 主工作台四种模式切换
- 空态、处理中、失败态
- 长文件名、长行为标签、通知堆叠
- 图片、视频、MJPEG 预览区域无重叠/截断/错位
- 按钮禁用态、加载态、重复点击行为

## 3. 数据与状态

- 任务状态从 `processing` 到 `completed/failed` 的一致性
- 前端轮询是否在停止/失败后结束
- 历史摘要与当前任务状态一致
- 批量导出 ZIP 中 `readme.txt` 与 `manifest.csv` 内容正确
- 刷新页面后当前模式、历史区和预览区恢复合理

## 4. 安全与环境

- 仓库默认配置中无硬编码弱密码
- `SECRET_KEY` 不再写死在仓库代码里
- 上传与输出文件需要登录访问
- 关键 API 未登录时返回重定向或拒绝访问
- 健康检查不污染正式数据库和正式输出目录
- Git `safe.directory` 问题有文档说明，且指向当前 D 盘正式仓库

## 5. 文档一致性

- README 只描述当前正式实现
- README 不再宣称双摄像头主链路能力
- 遗留前端资产有明确标识
- 脚本入口和检查入口说明可直接照做
