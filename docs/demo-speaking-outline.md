# 答辩讲解提纲

本提纲面向当前已经实现并验收过的系统界面，目标是在 3 到 5 分钟内把核心能力讲清楚。

对应界面主线：

- 顶部模式切换
- 左侧参数与模型区
- 中部输入与结果预览区
- 下方任务分析与历史记录区

建议固定演示素材：

- 单图：`testfile/0014012.jpg`
- 批量：`testfile/0009008.jpg`、`testfile/0009013.jpg`、`testfile/0009022.jpg`
- 视频：`testfile/QQ202618-01246-HD.mp4`

## 1. 开场（15 到 30 秒）

可以直接这样说：

“这是我的课堂行为检测系统。系统围绕课堂图片、批量图片、视频和实时摄像头四种输入场景，统一提供检测、统计、结果预览和报告导出能力。整个界面是为了答辩演示重新整理过的，主链路会尽量在一个工作台里完成。”

此时操作：

- 打开首页并登录
- 指一下顶部四个模式按钮
- 如果老师先问当前跑的是哪套模型，点击左侧“当前模型”，说明当前答辩入口默认从已验收的 `models/behavior.pt` 与 `models/head.pt` 启动

## 2. 单图检测（40 到 60 秒）

可以这样说：

“先看单图模式。这里适合快速展示模型对一张课堂图像的识别效果。左侧可以调整置信度、IOU 等参数，中间区域负责上传和预览，下面会自动生成行为统计和讲解摘要。”

此时操作：

1. 保持在“单图检测”
2. 选择 `testfile/0014012.jpg`
3. 点击“开始单图检测”
4. 展示检测结果图
5. 点击“原始 / 检测结果”切换
6. 往下看任务分析区和图表

建议强调：

- 识别结果不只是框选，还会生成行为统计
- 分析区会把学生行为和教师/人头行为分开展示
- 可以直接打开报告

## 3. 批量检测（40 到 60 秒）

可以这样说：

“批量模式主要解决多张课堂素材的一次性处理问题。它不是只给一张结果，而是支持多张图片统一检测、结果切换和汇总导出，更接近实际素材整理场景。”

此时操作：

1. 切到“批量检测”
2. 选择 `testfile/0009008.jpg`、`testfile/0009013.jpg`、`testfile/0009022.jpg`
3. 点击“开始批量检测”
4. 展示结果切换区
5. 说明历史记录中的批量导出入口

建议强调：

- 同一批素材可以统一处理
- 主预览区可以快速切换每张结果
- 历史记录支持多选后导出报告压缩包

## 4. 视频检测（40 到 60 秒）

可以这样说：

“视频模式更适合展示连续画面下的处理过程。系统会创建任务、轮询进度，并在完成后生成结果摘要和报告。”

此时操作：

1. 切到“视频检测”
2. 选择 `testfile/QQ202618-01246-HD.mp4`
3. 点击“开始视频检测”
4. 展示处理中状态
5. 处理完成后展示结果和分析区

建议强调：

- 视频不是一次性卡死等待，而是有任务状态反馈
- 完成后会进入和图片一致的分析与报告链路

## 5. 历史记录与报告（30 到 45 秒）

可以这样说：

“除了当前任务，系统还保留历史记录，支持筛选、排序、定位最新任务，以及批量导出报告。这一块主要服务于回看和材料整理。”

此时操作：

1. 滚到历史记录区
2. 演示“定位最新”或“定位高检测”
3. 勾选一个或多个任务
4. 展示“导出选中报告”按钮状态变化

建议强调：

- 当前任务和历史任务是打通的
- 历史记录不只是列表，还能继续生成可交付材料

## 6. 实时摄像头（20 到 40 秒）

可以这样说：

“实时摄像头模式用于现场巡检。系统会先做摄像头诊断，再启动实时检测，并在实时状态区展示反馈。”

此时操作：

1. 切到“实时摄像头”
2. 点击“诊断摄像头”
3. 若设备可用，再点击“启动摄像头”

建议强调：

- 这一模式和前面的上传式检测不同，先诊断设备再启动
- 界面会切换成实时巡检摘要视图

如果现场摄像头不可用，直接这样说：

“这台机器当前没有可用摄像头设备，所以这里我展示的是诊断和异常处理分支。系统主链路已经通过单图、批量和视频模式完整验证，不影响核心能力展示。”

## 7. 收束（15 到 30 秒）

可以这样说：

“整体上，这个系统把课堂行为检测拆成了统一的输入、识别、统计、回看和报告导出流程。除了功能实现，我还补了健康检查、回归脚本和答辩前检查清单，保证演示过程更稳定。”

此时操作：

- 回到顶部或停在分析区
- 如有需要，补一句已经具备一键总验收脚本

## 8. 建议的时间分配

- 开场：20 秒
- 单图检测：50 秒
- 批量检测：50 秒
- 视频检测：50 秒
- 历史记录与报告：35 秒
- 实时摄像头：25 秒
- 收束：20 秒

总计约 4 分钟 10 秒。

## 9. 不建议现场展开的内容

- 不要现场展开讲前端重构细节
- 不要现场逐条解释所有检测参数含义
- 不要把时间花在无设备的摄像头排障上
- 不要临时打开遗留资产或旧页面

答辩里更重要的是：

- 系统支持哪些输入场景
- 检测结果如何展示
- 统计和报告如何形成
- 系统是否考虑了演示稳定性
